# Penerjemah Game (Android)
1. Upload isi folder ini ke repo GitHub baru.
2. Buka tab Actions, jalankan "Build APK" (otomatis jalan saat push).
3. Setelah hijau, unduh artifact "PenerjemahGame-apk" dan pasang app-debug.apk.
4. Di app, isi API key Anthropic, pilih file dialog, terjemahkan, lalu unduh hasil (masuk folder Unduhan).
